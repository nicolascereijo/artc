ARtC provides local installers that set up an isolated environment with
Python 3.12.7 inside the project directory.
**It does not modify the system Python nor any global configuration**.

It works on both Linux and Windows 10/11.

Each installer performs the following actions:

1. Downloads a local copy of **Python 3.12.7**
   - Linux: full CPython built from source
   - Windows: embeddable distribution with `import site` enabled
2. Installs `pip` when necessary
   - Required on Windows (via get-pip.py)
3. Creates the local virtual environment `.artc`
   - Linux: `python -m venv`
   - Windows: `virtualenv` (because the embeddable Python cannot use `venv`)
4. Installs dependencies from `requirements.txt`
5. Installs the ARtC package using `pip install .`
6. Removes temporary installation files
7. Does not modify any global system configuration

> [!note]
> Installation may take several minutes.
> On Linux, Python must be compiled from source.
> On Windows, the duration depends mostly on download speed.

> [!warning]
> Installation may generate several hundred MB of data.
> Beyond the local Python environment, a set of test audio files is included.
> All files are free to use.

## 2.1. Prerequisites

The following components are required (standard build tools needed to compile Python from source):

- gcc
- make
- tar
- curl or wget

Debian/Ubuntu:

```bash
sudo apt install build-essential curl
```

Fedora/RHEL:

```bash
sudo dnf install gcc make tar wget
```

Arch/Manjaro:

```bash
sudo pacman -S --needed base-devel curl   # or replace curl with wget
```

> [!caution]
> Compiling Python may take between 2 and 10 minutes depending on hardware.

## 2.2. Installation

Grant permissions and run the installer:

```bash
chmod +x installers/artc_install_linux.sh
./installers/artc_install_linux.sh
```

## 2.3. Activate the virtual environment

```bash
source .artc/bin/activate
```

Deactivate with:

```bash
deactivate
```

The installer **does not require administrator privileges**.
The script uses a temporary *ExecutionPolicy Bypass* that does not modify the system.

## 3.1. Installation

Run:

```
installers\artc_install_windows.bat
```

This automatically triggers:

```
installers\artc_install_windows_core.ps1
```

> [!note]
> Downloading the embeddable Python may be slow on unstable connections.

## 3.2. Activate the virtual environment

PowerShell:

```powershell
.\.artc\Scripts\Activate.ps1
```

CMD:

```cmd
.artc\Scripts\activate.bat
```

Deactivate in PowerShell:

```powershell
deactivate
```

CMD:

```cmd
.artc\Scripts\deactivate.bat
```
