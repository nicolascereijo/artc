**ARtC (Audio Real-time Comparator)** is a software suite designed to compare and analyze audio files in real time.

[![MIT License](https://img.shields.io/badge/License-MIT-green.svg)](https://choosealicense.com/licenses/mit/)

**Installation**

For complete installation instructions for Linux and Windows, see:

- **[Installers Documentation](installers/README.md)**

This includes details on how to set up the local Python environment, create the virtual environment and install dependencies.

After completing the installation and activating the environment, the project demos can be run as regular Python scripts:

```python
python TEMPORARY_demo_compare.py
```

The demo_forest script is intended to be executed after the first one finishes, since it uses the files generated by the previous script as input.
